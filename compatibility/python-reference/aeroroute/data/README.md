# Map data

The bundled `ne_110m_land.geojson` and `ne_110m_admin_0_countries.geojson`
files come from [Natural Earth](https://www.naturalearthdata.com/) via the
Natural Earth vector repository. Natural Earth data is in the public domain.

The 1:110m scale is intentionally used for a clean, lightweight world-map
outline rather than street, terrain, or satellite detail.
